# はじめに
初めまして、enkeyです。
9/2(月) 〜 9/13(金)までの2週間でfreee株式会社の就業型インターンに参加してきました。
今回初投稿になります。

## 自己紹介
広島のとある情報系の大学院でネットワーク関連の研究をしています。
普段は、自宅サーバのお世話したり、気が向いた時にプログラミングをしたりゆるくやってます。
自身のプログラミング経験は以下の通りです。
- C, Python, Java: 主に大学の授業で使用
- Ruby: ハッカソンで使用経験あり
- Go: 研究で使用
- React: Portfolio作る時に少しだけ勉強した覚えが

※ 薄く広くやっているだけで競プロとかは解けません...

## 参加のきっかけ
私が大学院に入学後、就活サイトに色々登録したり、魔法のスプレッドシート見たりして
どこかいいインターンないかなぁと探していました。特に、研究でGoを使ってネットワーク周りの実装をしていたことからGoがかけるとこが理想でした。そんな中、freeeさんからアカリク経由でスカウトをいただきました。
もともとfreeeさんは知ってはいましたが、具体的に何をしている会社なのかは存じ上げていませんでした。
まぁ説明会ぐらいは参加してみるかなぁとそんな軽い気持ちでエントリーしました。

## 選考について
本インターンに参加するにあたり以下のような流れで選考を進めました。
1. 説明会の参加
    - マイクロサービスやってるやん！面白そう！になり応募してみることに
2. コーディングテストの受験
    - 2問あり、Pythonで受験しました。
    - 1問目は残り20分ぐらいでギリ解けたけど、2問目は...という感じでした
      (正直あんまり自信なかったです)
3. 面接
    - 主に聞かれたこと
        - 自己紹介
        - 研究について
        - 開発経験とその取り組み方
    - 逆質問では、Goとかマイクロサービス周りを聞いてました。
    
    そんなに硬い雰囲気ではなく、非常に話しやすかったことが印象に残っています。

## 参加まで
逆質問で技術的なことを色々聞いたのが功を奏したのか、合格通知をいただきました
メールをいただいた時は東京におり、インターンで知り合った人と夜ご飯を食べている時でした
当時、このような就業型のインターンのお祈りメールをたくさんいただいていたことから本当にびっくりした覚えがあります。

その後、リクルータ面談があり面接のフィードバックをしていただきました。
それからしばらく経ち、配属希望アンケートがやってきました。詳しいことは言えませんがチーム数の多さに企業規模の大きさを感じました。
配属どうしよう...になりますが、私はやりたいことが明確だったので希望するチームは絞れました。それでも希望順位をつけるのにすごい悩みましたね

配属先は... **「統合モジュール」** でした 
(第1希望ではなかったですが、納得はできる内容だったのでよかったです)

# インターンの概要について
以下がインターンの概要になります
- 期間: 9/2(月) 〜 9/13(金)
    - 基本的には10:00 ~ 19:00 (実稼働8時間)
- 1人のメンターさんにつき3人のインターン生が配属
- 就業型なのでもちろんお給料が発生
- 業務用のPC(Macbook Pro)が支給
    - 私はUS配列にしました
- 技術スタック
    - Rails
    - Go
    - React (TypeScript)
